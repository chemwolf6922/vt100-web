Shift+Tab leaves the terminal. Ctrl+Shift+V pastes; Ctrl+V sends ^V. Select text and Ctrl+C to copy; otherwise Ctrl+C goes to the device.

Before full-screen Linux apps: run export TERM=vt100 LC_ALL=C; stty rows 24 cols 80 at the shell prompt. Raw serial does not negotiate terminal type, window size, or encoding.

Connect a serial device

Select the connection parameters, then choose the device in your browser's port chooser.

The Raspberry Pi setup uses 115200 baud, 8-N-1, no flow control. Select COM7 in the browser chooser the first time. Previously authorized devices can be selected above; the browser exposes USB IDs rather than COM names.

VT100 SET-UP

Host-controlled settings show their current values. Save stores power-on defaults in this browser; Reset terminal recalls them.

Tab stops at the current cursor

Numeric keypad + represents the VT100 keypad comma. PF1-PF4 use F1-F4. In VT100 mode, F5-F10 use the keypad aliases expected by ncurses. Shift+BREAK is a long break; it can affect modem signals.
